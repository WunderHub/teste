# Colaboração no Vale do Sal

Leia README.md, docs/design-combate.md e docs/direcao-visual-terreno.md antes de trabalhar. Distinga funcionalidades implementadas de decisões aprovadas para etapas futuras. As referências visuais contêm limitações documentadas; não interpretar artefatos da geração como requisitos.

O usuário quer conhecer e aprovar propostas antes de alterações não solicitadas. Execute o escopo autorizado na conversa; não transforme discussão ou aprovação de conceito em autorização automática para implementar, integrar na main ou publicar. Não republicar o ambiente de nuvem sem instrução explícita.

Trabalhe em uma branch própria baseada na versão atual do repositório. Preserve alterações de outros colaboradores. Figma não faz parte do fluxo atual. Não introduzir Magnific sem nova instrução.

Mudanças no motor devem passar por npm test e npm run build. Alterações visuais e de interação exigem também verificação no navegador. Documentação e referências não exigem repetir testes do motor quando o código não muda.
